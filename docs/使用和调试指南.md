## 环境准备

### 1.1 系统要求

**硬件要求：**
- CPU: ≥4核（推荐8核）
- 内存: ≥8GB（推荐16GB）
- GPU: 可选，用于算法加速（NVIDIA GPU with CUDA）
- 存储: ≥100GB可用空间

**软件要求：**
- 操作系统: Linux (Ubuntu 20.04+) 或 Windows 10+
- Python: 3.9 或更高版本
- Docker: 20.10+ 和 Docker Compose 1.29+
- Node.js: 16+（前端开发需要）

**硬件设备：**
- 海康威视工业相机（支持RTSP）
- PLC设备（支持Modbus TCP协议）
- 网络：相机、PLC、服务器在同一网络

### 1.2 安装依赖

```bash
# 1. 克隆项目
git clone <repository-url>
cd semiconductor-nozzle-inspection-system

# 2. 创建Python虚拟环境
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 3. 安装Python依赖
pip install -r requirements.txt

# 4. 安装Docker（如果未安装）
# Ubuntu: sudo apt-get install docker.io docker-compose
# Windows: 下载Docker Desktop
```

## 系统配置

### 3.1 相机配置

**海康相机RTSP地址格式：**
```
rtsp://用户名:密码@IP地址:554/Streaming/Channels/101
```

**配置步骤：**
1. 确保相机已连接到网络
2. 在相机管理界面设置IP地址
3. 在`.env`文件中配置相机参数
4. 测试连接：
   ```bash
   # 使用ffmpeg测试
   ffmpeg -rtsp_transport tcp -i "rtsp://admin:password@192.168.1.64:554/Streaming/Channels/101" -frames:v 1 test.jpg
   ```

### 3.2 PLC配置

**Modbus TCP配置：**
- 从站ID（Slave ID）：通常为1
- 开始信号地址：线圈地址（如0）
- 停止信号地址：线圈地址（如1）

**测试PLC连接：**
```python
from pymodbus.client import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)
if client.connect():
    result = client.read_coils(0, 1, slave=1)
    print(f"信号状态: {result.bits[0]}")
    client.close()
```

### 3.3 标定配置

**标定板要求：**
- 棋盘格：推荐9×6或11×8
- 圆点：推荐7×5或9×6
- 方格大小：10mm（根据实际调整）

**标定参数配置：**
在`.env`文件中配置：
```env
ALGORITHM_CONFIG={"calibration": {
    "method": "chessboard",
    "board_size": [9, 6],
    "square_size_mm": 10.0,
    "min_images": 10
}}
```

## 使用流程

### 4.1 首次使用 - 标定流程

**步骤1：准备标定板**
- 确保标定板平整、清洁
- 放置在相机视野内

**步骤2：启动标定**
```bash
# 通过API启动标定
curl -X POST "http://localhost:8000/api/v1/calibration/start" \
  -H "Content-Type: application/json" \
  -d '{
    "method": "chessboard",
    "board_size": [9, 6],
    "square_size_mm": 10.0
  }'
```

**步骤3：采集标定图像**
- 采集至少10张不同角度的图像
- 确保标定板覆盖整个视野
- 确保图像清晰

```bash
# 上传标定图像
curl -X POST "http://localhost:8000/api/v1/calibration/upload-image" \
  -F "file=@calibration_image_1.jpg" \
  -F "calibration_id=cal_12345"
```

**步骤4：计算标定参数**
```bash
curl -X POST "http://localhost:8000/api/v1/calibration/calculate" \
  -H "Content-Type: application/json" \
  -d '{"calibration_id": "cal_12345"}'
```

**步骤5：验证标定精度**
- 检查重投影误差（应<0.1像素）
- 检查像素到物理坐标转换精度（应达到0.05mm）

### 4.2 配置检测参数

**通过API配置：**
```bash
# 配置回吸高度阈值
curl -X POST "http://localhost:8000/api/v1/config/update" \
  -H "Content-Type: application/json" \
  -d '{
    "algorithm": "suction_height",
    "parameters": {
      "min_mm": 3.0,
      "max_mm": 5.0
    }
  }'
```

**配置项说明：**
- `offset_threshold_mm`: 偏移距离阈值（默认0.1mm）
- `angle_threshold_deg`: 角度偏移阈值（默认2.0°）
- `contamination_threshold`: 脏污阈值（默认0.3）
- `suction_height_min_mm`: 回吸高度最小值（默认3.0mm）
- `suction_height_max_mm`: 回吸高度最大值（默认5.0mm）

### 4.3 启动检测

**步骤1：连接相机和PLC**
```bash
# 连接相机（自动连接，检查日志确认）
# 连接PLC（自动连接，检查日志确认）
```

**步骤2：启动检测**
```bash
curl -X POST "http://localhost:8000/api/v1/detection/start" \
  -H "Content-Type: application/json" \
  -d '{
    "camera_id": "default",
    "algorithms": ["nozzle_offset", "suction_height", "liquid_width"]
  }'
```

**步骤3：PLC信号触发**
- PLC发送开始信号 → 系统自动开始录制和检测
- PLC发送停止信号 → 系统自动停止录制

**步骤4：查看结果**
```bash
# 获取检测结果
curl "http://localhost:8000/api/v1/detection/results?camera_id=default&limit=10"
```

## 常见问题

### 7.1 相机连接问题

**问题：无法连接海康相机**

**排查步骤：**
1. 检查相机IP地址是否正确
   ```bash
   ping 192.168.1.64
   ```

2. 检查RTSP地址格式
   ```
   rtsp://用户名:密码@IP:554/Streaming/Channels/101
   ```

3. 使用ffmpeg测试连接
   ```bash
   ffmpeg -rtsp_transport tcp -i "rtsp://..." -frames:v 1 test.jpg
   ```

4. 检查防火墙设置
   ```bash
   # Linux
   sudo ufw allow 554/tcp
   ```

5. 查看后端日志
   ```bash
   tail -f backend/logs/app.log | grep camera
   ```

**解决方案：**
- 确认相机用户名和密码
- 检查相机是否支持RTSP
- 确认网络连接正常
- 检查相机固件版本

### 7.2 PLC通信问题

**问题：无法读取PLC信号**

**排查步骤：**
1. 检查PLC IP和端口
   ```bash
   telnet 192.168.1.100 502
   ```

2. 检查Modbus配置
   - 从站ID是否正确
   - 地址是否正确
   - 数据类型是否正确（线圈/保持寄存器）

3. 使用Modbus调试工具测试
   - Modbus Poll（Windows）
   - QModMaster（Linux）

4. 查看PLC日志
   ```bash
   tail -f backend/logs/app.log | grep plc
   ```

**解决方案：**
- 确认PLC Modbus配置
- 检查网络连接
- 确认从站ID和地址
- 检查PLC程序中的信号地址

### 7.3 标定精度问题

**问题：标定精度不达标（重投影误差>0.1像素）**

**排查步骤：**
1. 检查标定图像质量
   - 图像是否清晰
   - 标定板是否平整
   - 光照是否均匀

2. 检查标定图像数量
   - 至少需要10张
   - 推荐15-20张

3. 检查标定板覆盖范围
   - 标定板应覆盖整个视野
   - 不同角度和位置

4. 检查标定参数
   - 棋盘格大小是否正确
   - 方格大小是否正确

**解决方案：**
- 增加标定图像数量
- 确保标定板平整
- 改善光照条件
- 检查相机焦距设置

### 7.4 检测精度问题

**问题：检测精度无法达到0.05mm**

**排查步骤：**
1. 检查标定参数
   ```bash
   curl http://localhost:8000/api/v1/calibration/parameters
   ```

2. 检查相机分辨率
   - 建议≥4MP（2048×2048）
   - 检查实际分辨率设置

3. 检查算法参数
   - 亚像素处理是否启用
   - 边缘检测参数是否合适

4. 检查视野大小
   - 视野越小，精度越高
   - 建议视野≤10mm×10mm

**解决方案：**
- 重新标定，确保精度
- 使用更高分辨率相机
- 缩小视野范围
- 优化算法参数

### 7.5 实时性问题

**问题：无法达到60fps处理速度**

**排查步骤：**
1. 检查CPU使用率
   ```bash
   top
   ```

2. 检查算法处理时间
   ```python
   import time
   start = time.time()
   result = algorithm.detect(frame)
   print(f"处理时间: {(time.time() - start) * 1000:.2f}ms")
   ```

3. 检查帧率设置
   ```bash
   # 检查相机实际帧率
   # 检查处理线程是否阻塞
   ```

**解决方案：**
- 使用GPU加速（CUDA）
- 优化算法，减少计算量
- 使用帧采样（非关键帧降低频率）
- 优化ROI区域
- 升级硬件配置

### 7.6 存储问题

**问题：视频上传MinIO失败**

**排查步骤：**
1. 检查MinIO连接
   ```bash
   curl http://localhost:9000/minio/health/live
   ```

2. 检查存储桶是否存在
   ```bash
   mc ls minio/nozzle-videos
   ```

3. 检查磁盘空间
   ```bash
   df -h
   ```

4. 查看MinIO日志
   ```bash
   docker-compose logs minio
   ```

**解决方案：**
- 检查MinIO配置
- 确保存储桶存在
- 清理磁盘空间
- 检查网络连接
