### 2.1 喷嘴偏移距离检测

#### 算法原理
通过模板匹配和特征点检测，定位喷嘴中心位置，计算与标准位置的偏移量。

#### 实现步骤
1. **ROI提取**
   ```python
   # 提取喷嘴区域
   roi = image[y1:y2, x1:x2]
   ```

2. **模板匹配**
   ```python
   # 使用标准模板进行匹配
   result = cv2.matchTemplate(roi, template, cv2.TM_CCOEFF_NORMED)
   min_val, max_val, min_loc, max_loc = cv2.minMaxLoc(result)
   ```

3. **亚像素级定位**
   ```python
   # 亚像素级精确定位
   center_x = max_loc[0] + template.shape[1] / 2
   center_y = max_loc[1] + template.shape[0] / 2
   ```

4. **偏移计算**
   ```python
   # 计算像素偏移
   offset_x_pixel = center_x - standard_x
   offset_y_pixel = center_y - standard_y
   
   # 转换为物理距离（mm）
   offset_x_mm = offset_x_pixel * pixel_size_x
   offset_y_mm = offset_y_pixel * pixel_size_y
   offset_distance = sqrt(offset_x_mm^2 + offset_y_mm^2)
   ```

#### 精度保证
- 使用亚像素级模板匹配
- 多尺度模板匹配
- 边缘增强预处理

### 2.2 喷嘴角度偏移检测

#### 算法原理
通过轮廓提取和直线拟合，计算喷嘴轴线角度，与标准角度对比。

#### 实现步骤
1. **轮廓提取**
   ```python
   # 二值化
   gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
   _, binary = cv2.threshold(gray, threshold, 255, cv2.THRESH_BINARY)
   
   # 轮廓检测
   contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
   ```

2. **轮廓筛选**
   ```python
   # 筛选喷嘴轮廓（面积、长宽比）
   nozzle_contour = None
   for contour in contours:
       area = cv2.contourArea(contour)
       if min_area < area < max_area:
           x, y, w, h = cv2.boundingRect(contour)
           aspect_ratio = w / h
           if min_aspect < aspect_ratio < max_aspect:
               nozzle_contour = contour
               break
   ```

3. **直线拟合**
   ```python
   # 使用最小二乘法拟合直线
   [vx, vy, x0, y0] = cv2.fitLine(nozzle_contour, cv2.DIST_L2, 0, 0.01, 0.01)
   angle = math.atan2(vy, vx) * 180 / math.pi
   ```

4. **角度偏移计算**
   ```python
   angle_offset = angle - standard_angle
   if angle_offset > 180:
       angle_offset -= 360
   elif angle_offset < -180:
       angle_offset += 360
   ```

#### 精度保证
- 使用最小二乘法拟合
- 轮廓平滑处理
- 多帧平均

### 2.3 喷嘴脏污检测

#### 算法原理
通过纹理分析和深度学习分类，检测喷嘴表面的脏污情况。

#### 方法一：纹理分析
1. **纹理特征提取**
   ```python
   # LBP (Local Binary Pattern)
   lbp = local_binary_pattern(gray, 8, 1, method='uniform')
   
   # GLCM (Gray-Level Co-occurrence Matrix)
   glcm = graycomatrix(gray, [1], [0, np.pi/4, np.pi/2, 3*np.pi/4])
   contrast = graycoprops(glcm, 'contrast')
   homogeneity = graycoprops(glcm, 'homogeneity')
   ```

2. **特征对比**
   ```python
   # 与标准特征对比
   feature_diff = abs(current_features - standard_features)
   contamination_score = np.mean(feature_diff)
   ```

#### 方法二：深度学习
1. **模型架构**
   ```python
   # 使用ResNet或MobileNet作为backbone
   model = ResNet50(pretrained=True)
   # 添加分类头
   classifier = nn.Sequential(
   ```

2. **推理**

   ```python
   # 推理
   ```

### 2.4 喷嘴挂滴检测

#### 算法原理
通过轮廓检测和形状分析，检测喷嘴下方是否有挂滴。

#### 实现步骤
1. **ROI提取**
   ```python
   # 提取喷嘴下方区域
   roi = image[nozzle_y:nozzle_y+drop_region_height, x1:x2]
   ```

2. **前景提取**
   ```python
   # 背景差分或阈值分割
   diff = cv2.absdiff(roi, background)
   _, binary = cv2.threshold(diff, threshold, 255, cv2.THRESH_BINARY)
   ```

3. **形态学处理**
   ```python
   # 去除噪声
   kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
   binary = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)
   binary = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)
   ```

4. **轮廓检测**
   ```python
   contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
   
   # 筛选挂滴轮廓
   drops = []
   for contour in contours:
       area = cv2.contourArea(contour)
       if min_drop_area < area < max_drop_area:
           # 形状分析
           x, y, w, h = cv2.boundingRect(contour)
           aspect_ratio = h / w  # 挂滴通常高度大于宽度
           if aspect_ratio > min_aspect_ratio:
               drops.append(contour)
   ```

5. **挂滴判断**
   ```python
   has_hanging_drop = len(drops) > 0
   drop_size = sum([cv2.contourArea(d) for d in drops])
   ```

#### 精度保证
- 自适应阈值
- 多帧验证
- 形状特征筛选

### 2.5 喷嘴掉滴检测

#### 算法原理
通过帧间差分和运动检测，检测液滴掉落事件。

#### 实现步骤
1. **帧间差分**
   ```python
   # 连续帧差分
   diff1 = cv2.absdiff(frame_n, frame_n_minus_1)
   diff2 = cv2.absdiff(frame_n_minus_1, frame_n_minus_2)
   motion = cv2.bitwise_and(diff1, diff2)
   ```

2. **运动区域提取**
   ```python
   _, binary = cv2.threshold(motion, threshold, 255, cv2.THRESH_BINARY)
   kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
   binary = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)
   ```

3. **运动目标检测**
   ```python
   contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
   
   # 筛选运动目标
   moving_objects = []
   for contour in contours:
       area = cv2.contourArea(contour)
       if min_drop_area < area < max_drop_area:
           # 计算运动方向（向下）
           moments = cv2.moments(contour)
           cx = int(moments['m10'] / moments['m00'])
           cy = int(moments['m01'] / moments['m00'])
           # 与上一帧位置对比
           if is_moving_downward(cx, cy, prev_positions):
               moving_objects.append(contour)
   ```

4. **掉滴判断**
   ```python
   # 检测到向下运动的液滴
   has_dropping = len(moving_objects) > 0
   ```

#### 精度保证
- 多帧验证
- 运动轨迹分析
- 速度阈值判断

### 2.6 喷嘴损坏检测

#### 算法原理
通过模板匹配和缺陷检测，识别喷嘴的损坏情况。

#### 实现步骤
1. **模板匹配**
   ```python
   # 使用标准喷嘴模板
   result = cv2.matchTemplate(image, template, cv2.TM_CCOEFF_NORMED)
   ```

2. **差异区域检测**
   ```python
   # 对齐后差分
   aligned_image = align_image(image, template)
   diff = cv2.absdiff(aligned_image, template)
   _, binary = cv2.threshold(diff, threshold, 255, cv2.THRESH_BINARY)
   ```

3. **缺陷区域提取**
   ```python
   contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
   
   defects = []
   for contour in contours:
       area = cv2.contourArea(contour)
       if area > min_defect_area:
           # 缺陷特征
           x, y, w, h = cv2.boundingRect(contour)
           defects.append({
               'area': area,
               'bbox': (x, y, w, h),
               'contour': contour
           })
   ```

4. **损坏程度评估**
   ```python
   total_defect_area = sum([d['area'] for d in defects])
   damage_ratio = total_defect_area / nozzle_area
   
   if damage_ratio > severe_threshold:
       damage_level = 'severe'
   elif damage_ratio > moderate_threshold:
       damage_level = 'moderate'
   else:
       damage_level = 'minor'
   ```

### 2.7 喷液回吸高度检测

#### 算法原理
通过液面边缘检测，测量液面到喷嘴的距离。

#### 实现步骤
1. **ROI提取**
   ```python
   # 提取喷嘴和液面区域
   roi = image[nozzle_y - max_height:nozzle_y + margin, x1:x2]
   ```

2. **液面检测**
   ```python
   # 边缘检测
   edges = cv2.Canny(roi, threshold1, threshold2)
   
   # 霍夫直线检测（水平线）
   lines = cv2.HoughLinesP(edges, 1, np.pi/180, threshold, minLineLength, maxLineGap)
   
   # 筛选水平线（液面）
   liquid_surface_lines = []
   for line in lines:
       x1, y1, x2, y2 = line[0]
       angle = math.atan2(y2 - y1, x2 - x1) * 180 / math.pi
       if abs(angle) < 5:  # 接近水平
           liquid_surface_lines.append(line)
   ```

3. **液面位置确定**
   ```python
   # 取最上方的水平线作为液面
   if liquid_surface_lines:
       surface_y = min([min(line[0][1], line[0][3]) for line in liquid_surface_lines])
   else:
       # 使用轮廓检测
       contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
       surface_y = min([min(contour[:, 0, 1]) for contour in contours])
   ```

4. **高度计算**
   ```python
   # 计算像素距离
   height_pixel = nozzle_y - surface_y
   
   # 转换为物理高度（mm）
   height_mm = height_pixel * pixel_size_y
   ```

#### 精度保证
- 亚像素边缘检测
- 多帧平均
- 温度补偿（如需要）

### 2.8 喷液宽度检测

#### 算法原理
通过边缘检测，测量喷液的最大宽度。

#### 实现步骤
1. **ROI提取**
   ```python
   # 提取喷液区域
   roi = image[y1:y2, x1:x2]
   ```

2. **边缘检测**
   ```python
   # Canny边缘检测
   edges = cv2.Canny(roi, threshold1, threshold2)
   
   # 或使用Sobel
   sobelx = cv2.Sobel(roi, cv2.CV_64F, 1, 0, ksize=3)
   sobely = cv2.Sobel(roi, cv2.CV_64F, 0, 1, ksize=3)
   edges = np.sqrt(sobelx**2 + sobely**2)
   ```

3. **宽度测量**
   ```python
   # 垂直投影
   projection = np.sum(edges, axis=0)
   
   # 找到左右边界
   left_edge = np.where(projection > threshold)[0][0]
   right_edge = np.where(projection > threshold)[0][-1]
   
   # 计算宽度
   width_pixel = right_edge - left_edge
   width_mm = width_pixel * pixel_size_x
   ```

4. **多位置测量**
   ```python
   # 在不同高度测量宽度，取最大值
   widths = []
   for y in range(y1, y2, step):
       row_edges = edges[y, :]
       left = np.where(row_edges > 0)[0][0] if len(np.where(row_edges > 0)[0]) > 0 else None
       right = np.where(row_edges > 0)[0][-1] if len(np.where(row_edges > 0)[0]) > 0 else None
       if left is not None and right is not None:
           widths.append(right - left)
   
   max_width_pixel = max(widths) if widths else 0
   max_width_mm = max_width_pixel * pixel_size_x
   ```

#### 精度保证
- 亚像素边缘检测
- 多行平均
- 边缘增强

### 2.9 液体气泡检测

#### 算法原理
通过形态学处理和连通域分析，检测液体中的气泡。

#### 实现步骤
1. **预处理**
   ```python
   # 转换为灰度图
   gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
   
   # 高斯模糊
   blurred = cv2.GaussianBlur(gray, (5, 5), 0)
   ```

2. **二值化**
   ```python
   # 自适应阈值或OTSU
   _, binary = cv2.threshold(blurred, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
   
   # 或使用自适应阈值
   binary = cv2.adaptiveThreshold(blurred, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, 
                                   cv2.THRESH_BINARY, 11, 2)
   ```

3. **形态学处理**
   ```python
   # 开运算去除小噪声
   kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
   binary = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)
   
   # 闭运算连接断开的边缘
   binary = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)
   ```

4. **连通域分析**
   ```python
   # 查找连通域
   num_labels, labels, stats, centroids = cv2.connectedComponentsWithStats(binary)
   
   # 筛选气泡（圆形、面积范围）
   bubbles = []
   for i in range(1, num_labels):  # 0是背景
       area = stats[i, cv2.CC_STAT_AREA]
       if min_bubble_area < area < max_bubble_area:
           # 提取轮廓
           mask = (labels == i).astype(np.uint8) * 255
           contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
           
           if contours:
               contour = contours[0]
               # 圆形度检测
               perimeter = cv2.arcLength(contour, True)
               if perimeter > 0:
                   circularity = 4 * np.pi * area / (perimeter ** 2)
                   if circularity > min_circularity:  # 接近1表示圆形
                       bubbles.append({
                           'area': area,
                           'centroid': centroids[i],
                           'contour': contour
                       })
   ```

5. **气泡统计**
   ```python
   bubble_count = len(bubbles)
   total_bubble_area = sum([b['area'] for b in bubbles])
   bubble_density = bubble_count / roi_area
   ```

#### 精度保证
- 多尺度检测
- 形状特征筛选
- 深度学习辅助（如需要）
