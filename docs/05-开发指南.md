## 项目结构

```
semiconductor-nozzle-inspection-system/
├── backend/                    # 后端服务
│   ├── video_capture/         # 视频采集模块
│   ├── algorithm/             # 算法处理模块
│   ├── storage/               # 存储模块
│   ├── communication/         # 通信模块
│   ├── config/                # 配置管理
│   ├── api/                   # API接口
│   └── main.py               # 主程序入口
├── frontend/                   # 前端应用（待开发）
├── docs/                       # 项目文档
├── docker-compose.yml          # Docker编排
└── requirements.txt            # Python依赖
```

### 模块说明

**backend/video_capture/**
- `camera_manager.py`: 管理海康相机连接、视频流采集

**backend/algorithm/**
- `base.py`: 检测算法基类
- `nozzle_offset.py`: 喷嘴偏移检测算法（示例）

**backend/storage/**
- `minio_client.py`: MinIO对象存储客户端

**backend/communication/**
- `mqtt_client.py`: MQTT消息发布和订阅
- `plc_client.py`: Modbus TCP通信

**backend/config/**
- `settings.py`: 系统配置管理

**backend/api/**
- `routes.py`: FastAPI路由定义

## 开发环境

### 环境要求

- Python 3.9+
- Docker & Docker Compose
- Git

### 设置开发环境

```bash
# 1. 克隆项目
git clone <repository-url>
cd semiconductor-nozzle-inspection-system

# 2. 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 安装开发依赖
pip install pytest pytest-asyncio pytest-cov black flake8 mypy

# 5. 启动基础设施
docker-compose up -d
```

### 开发模式

```bash
# 启用调试模式
export DEBUG=true

# 启动后端（自动重载）
python backend/main.py
```

## 代码规范

### 命名规范

- **文件名**: 小写字母+下划线（snake_case）
- **类名**: 大驼峰（PascalCase）
- **函数/变量**: 小写字母+下划线（snake_case）
- **常量**: 大写字母+下划线（UPPER_SNAKE_CASE）

### 代码格式

使用 `black` 格式化代码：
```bash
black backend/
```

使用 `flake8` 检查代码：
```bash
flake8 backend/
```

### 类型提示

使用类型提示提高代码可读性：
```python
from typing import Optional, Dict, Any
import numpy as np

def detect(self, image: np.ndarray, roi: Optional[np.ndarray] = None) -> Dict[str, Any]:
    """执行检测"""
    pass
```

### 文档字符串

关键函数和类需要文档字符串：
```python
def detect(self, image: np.ndarray, roi: Optional[np.ndarray] = None) -> Dict[str, Any]:
    """
    执行检测
    
    Args:
        image: 输入图像
        roi: 感兴趣区域（可选）
        
    Returns:
        检测结果字典
    """
    pass
```

## 扩展开发

### 添加新算法

1. **创建算法文件**
   ```bash
   backend/algorithm/new_algorithm.py
   ```

2. **实现算法类**
   ```python
   from .base import DetectionAlgorithm
   from typing import Dict, Any, Optional
   import numpy as np
   
   class NewAlgorithm(DetectionAlgorithm):
       def __init__(self, config: Dict[str, Any]):
           super().__init__(config)
           self.threshold = config.get('threshold', 0.1)
       
       def detect(self, image: np.ndarray, roi: Optional[np.ndarray] = None) -> Dict[str, Any]:
           # 实现检测逻辑
           result = {
               'value': 0.05,
               'status': 'normal'
           }
           return {
               'algorithm_name': 'new_algorithm',
               'result': result,
               'status': result['status']
           }
       
       def annotate_result(self, image: np.ndarray, result: Dict[str, Any]) -> np.ndarray:
           # 实现标注逻辑
           annotated = image.copy()
           # 添加标注
           return annotated
   ```

3. **注册API**
   在 `backend/api/routes.py` 中添加路由

### 添加新API

1. **定义路由**
   ```python
   @router.post("/new-endpoint")
   async def new_endpoint(request: RequestModel):
       # 实现逻辑
       return {"message": "success"}
   ```

2. **定义模型**
   ```python
   from pydantic import BaseModel
   
   class RequestModel(BaseModel):
       field1: str
       field2: int
   ```

### 添加新服务

1. **创建服务模块**
   ```bash
   backend/new_service/
   ├── __init__.py
   └── service.py
   ```

2. **实现服务逻辑**
   ```python
   class NewService:
       def __init__(self, config):
           self.config = config
       
       async def start(self):
           pass
       
       async def stop(self):
           pass
   ```

3. **在main.py中初始化**
   ```python
   from backend.new_service.service import NewService
   
   new_service = None
   
   @app.on_event("startup")
   async def startup_event():
       global new_service
       new_service = NewService(settings.NEW_SERVICE_CONFIG)
       await new_service.start()
   ```

## 测试指南

### 单元测试

创建测试文件：
```bash
tests/test_algorithm.py
```

编写测试：
```python
import pytest
from backend.algorithm.nozzle_offset import NozzleOffsetDetection

def test_nozzle_offset_detection():
    config = {'threshold_mm': 0.1}
    algorithm = NozzleOffsetDetection(config)
    # 测试逻辑
    assert algorithm is not None
```

运行测试：
```bash
pytest tests/
```

### API测试

使用pytest测试API：
```python
from fastapi.testclient import TestClient
from backend.main import app

client = TestClient(app)

def test_health_check():
    response = client.get("/health")
    assert response.status_code == 200
    assert response.json()["status"] == "healthy"
```

测试完整流程：

2. 调用API
3. 验证结果
4. 清理资源
