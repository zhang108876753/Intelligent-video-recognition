## 模块说明

### backend/ - 后端服务

**main.py**
- FastAPI应用入口
- 服务启动和关闭逻辑
- 全局对象初始化（相机、MQTT、MinIO）

**video_capture/** - 视频采集模块
- `camera_manager.py`: 管理海康相机连接、视频流采集、录制控制

**algorithm/** - 算法处理模块
- `base.py`: 检测算法基类，提供统一接口和像素转换功能
- `nozzle_offset.py`: 喷嘴偏移检测算法示例
- 其他8种算法待实现

**storage/** - 存储模块
- `minio_client.py`: MinIO对象存储客户端，处理视频上传和下载

**communication/** - 通信模块
- `mqtt_client.py`: MQTT消息发布和订阅
- `plc_client.py`: Modbus TCP通信，监听PLC信号

**config/** - 配置管理
- `settings.py`: 系统配置管理，使用pydantic-settings

**api/** - API接口
- `routes.py`: FastAPI路由定义，提供RESTful API

### docs/ - 文档目录

- **使用和调试指南.md**: 完整的使用说明、API接口、调试方法和常见问题
- **算法详细设计.md**: 9种检测算法的详细设计文档
- **项目结构说明.md**: 项目结构说明（本文件）

### 配置文件

**docker-compose.yml**
- PostgreSQL数据库服务
- Redis缓存服务
- MinIO对象存储服务
- Mosquitto MQTT Broker

**requirements.txt**
- Python依赖包列表

**.env.example**
- 环境变量配置模板
- 包含相机、PLC、MinIO、MQTT等配置项

**.gitignore**
- Git版本控制忽略文件
- 排除临时文件、日志、视频等

## 开发规范

### 代码组织
- 每个模块独立目录
- 使用`__init__.py`标识Python包
- 模块间通过接口交互，降低耦合

### 命名规范
- 文件名：小写字母+下划线（snake_case）
- 类名：大驼峰（PascalCase）
- 函数/变量：小写字母+下划线（snake_case）

### 配置管理
- 使用`.env`文件管理环境变量
- 使用`pydantic-settings`进行配置验证
- 敏感信息不提交到版本控制

### 文档要求
- 关键函数和类需要文档字符串
- API接口自动生成文档（FastAPI）
- 重要变更更新文档

## 扩展指南

### 添加新算法
1. 在`backend/algorithm/`目录创建新文件
2. 继承`DetectionAlgorithm`基类
3. 实现`detect()`和`annotate_result()`方法
4. 在`backend/api/routes.py`中注册API

### 添加新API
1. 在`backend/api/routes.py`中添加路由
2. 定义请求/响应模型
3. 实现业务逻辑
4. 更新API文档

### 添加新服务
1. 在`backend/`目录创建新模块
2. 实现服务逻辑
3. 在`main.py`中初始化
4. 更新配置和文档
