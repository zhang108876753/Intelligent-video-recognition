## 算法概述

本系统实现9种检测算法，用于检测半导体喷胶显影设备的喷嘴状态。所有算法继承自统一的基类，提供一致的接口和像素到物理坐标转换功能。

### 核心特性
- **精度要求**: 0.05mm
- **处理速度**: 60fps实时处理
- **坐标转换**: 自动像素到物理坐标转换（mm）
- **结果标注**: 自动在图像上标注检测结果

```python
        pass
    
    def set_calibration(self, calibration_params: Dict[str, Any]):
        """设置标定参数"""
        pass
    
    def detect(self, image: np.ndarray, roi: Optional[np.ndarray] = None) -> Dict[str, Any]:
        """执行检测"""
        pass
    
    def annotate_result(self, image: np.ndarray, result: Dict[str, Any]) -> np.ndarray:
        """标注检测结果"""
        pass
    
    def pixel_to_physical(self, pixel_value: float, axis: str = 'x') -> float:
        """像素值转换为物理值（mm）"""
        pass
```

## 实现示例

### 1. 喷嘴偏移距离检测

**算法原理**: 通过模板匹配定位喷嘴中心，计算与标准位置的偏移量

**实现文件**: `backend/algorithm/nozzle_offset.py`

**关键步骤**:
1. ROI提取
2. 模板匹配
3. 亚像素级定位
4. 偏移计算和坐标转换

**配置参数**:
- `threshold_mm`: 偏移阈值（默认0.1mm）

### 2. 喷嘴角度偏移检测

**算法原理**: 通过轮廓提取和直线拟合计算喷嘴轴线角度

**关键步骤**:
1. 轮廓提取
2. 轮廓筛选
3. 直线拟合
4. 角度计算

**配置参数**:
- `threshold_deg`: 角度阈值（默认2.0°）

### 3. 其他算法

详细实现方案请参考代码注释和算法设计文档。

## 算法开发指南

### 添加新算法

1. **创建算法文件**
   ```bash
   backend/algorithm/new_algorithm.py
   ```

2. **继承基类**
   ```python
   from .base import DetectionAlgorithm
   
   class NewAlgorithm(DetectionAlgorithm):
       def detect(self, image, roi=None):
           # 实现检测逻辑
           pass
   ```

3. **实现核心方法**
   - `detect()`: 执行检测
   - `annotate_result()`: 标注结果

4. **注册API**
   - 在 `backend/api/routes.py` 中添加路由
   - 更新配置文档

### 精度保证

- 使用亚像素级处理
- 多帧平均
- 精密标定
- 算法优化

### 性能优化

- 使用ROI减少处理区域
- GPU加速（可选）
- 多线程处理
- 帧采样策略
