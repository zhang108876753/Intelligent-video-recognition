# 快速开始指南

## 一、环境准备

### 1.1 系统要求

- **操作系统**：Linux (Ubuntu 20.04+) 或 Windows 10+
- **Python**：3.9 或更高版本
- **Docker**：20.10+ 和 Docker Compose 1.29+
- **内存**：≥8GB（推荐16GB）
- **CPU**：≥4核（推荐8核）
- **GPU**：可选，用于加速（NVIDIA GPU with CUDA支持）

### 1.2 硬件要求

- **工业相机**：海康威视工业相机（支持RTSP）
- **PLC设备**：支持Modbus TCP协议
- **网络**：相机、PLC、服务器在同一网络

## 二、安装步骤

### 2.1 克隆项目

```bash
git clone <repository-url>
cd semiconductor-nozzle-inspection-system
```

### 2.2 创建Python虚拟环境

```bash
# Linux/Mac
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

### 2.3 安装Python依赖

```bash
pip install -r requirements.txt
```

### 2.4 配置环境变量

```bash

cp .env.example .env

# 编辑.env文件，配置以下参数：
# - 相机IP、用户名、密码

# - MinIO、MQTT、数据库配置
```

### 2.5 启动基础设施服务

```bash

# 检查服务状态

```

## 三、首次使用

### 3.1 标定流程

1. **准备标定板**
   - 使用棋盘格标定板（推荐9×6）
   - 或使用圆点标定板

2. **启动标定**
   - 打开Web界面
   - 进入"标定"页面
   - 点击"开始标定"

3. **采集标定图像**
   - 将标定板放置在相机视野内
   - 调整标定板位置和角度
   - 采集至少10张不同角度的图像

4. **计算标定参数**
   - 点击"计算标定参数"
   - 等待计算完成
   - 查看标定精度（应<0.1像素）

5. **保存标定参数**
   - 标定精度满足要求后
   - 点击"保存标定参数"

### 3.2 配置检测参数

1. **进入配置页面**
   - 打开Web界面
   - 进入"配置"页面

2. **设置阈值参数**
   - 偏移距离阈值：0.1mm
   - 角度偏移阈值：2.0°
   - 回吸高度范围：3-5mm
   - 其他参数根据实际需求设置

3. **保存配置**
   - 点击"保存配置"
   - 配置将实时生效

### 3.3 开始检测

1. **连接相机**
   - 确保相机已连接并配置正确
   - 在Web界面点击"连接相机"

2. **连接PLC**
   - 确保PLC已连接并配置正确
   - 在Web界面点击"连接PLC"

3. **启动检测**
   - 点击"开始检测"
   - 系统将等待PLC信号

4. **PLC信号触发**
   - PLC发送开始信号
   - 系统自动开始录制和检测
   - 实时显示检测结果

5. **查看结果**
   - 在"实时监控"页面查看检测结果
   - 在"历史记录"页面查看历史数据
   - 在"视频回放"页面查看视频和标注

## 四、API使用示例

### 4.1 启动检测

```bash
curl -X POST "http://localhost:8000/api/v1/detection/start" \
  -H "Content-Type: application/json" \
  -d '{
    "camera_id": "default",
    "algorithms": ["nozzle_offset", "suction_height"]
  }'
```

### 4.2 获取检测结果

```bash
curl "http://localhost:8000/api/v1/detection/results?camera_id=default&limit=10"
```

### 4.3 更新配置

```bash
curl -X POST "http://localhost:8000/api/v1/config/update" \
  -H "Content-Type: application/json" \
  -d '{
    "algorithm": "suction_height",
    "parameters": {
      "min_mm": 3.0,
      "max_mm": 5.0
    }
  }'
```

## 五、常见问题

### 5.1 相机连接失败

**问题**：无法连接海康相机

**解决方案**：
1. 检查相机IP地址是否正确
2. 检查网络连接
3. 检查用户名和密码
4. 检查相机是否支持RTSP
5. 查看后端日志获取详细错误信息

### 5.2 PLC通信失败

**问题**：无法读取PLC信号

**解决方案**：
1. 检查PLC IP地址和端口
2. 检查Modbus配置（从站ID、地址）
3. 检查网络连接
4. 使用Modbus调试工具测试连接

### 5.3 标定精度不达标

**问题**：标定重投影误差>0.1像素

**解决方案**：
1. 增加标定图像数量（≥15张）
2. 确保标定板平整
3. 确保标定图像清晰
4. 确保标定板覆盖整个视野
5. 检查相机焦距和视野设置

### 5.4 检测精度不达标

**问题**：检测精度无法达到0.05mm

**解决方案**：
1. 检查标定参数是否正确
2. 检查相机分辨率（建议≥4MP）
3. 优化算法参数
4. 使用亚像素级处理
5. 检查光照条件

### 5.5 实时性不达标

**问题**：无法达到60fps处理速度

**解决方案**：
1. 使用GPU加速
2. 优化算法，减少计算量
3. 使用帧采样（非关键帧降低处理频率）
4. 优化ROI区域
5. 升级硬件配置
