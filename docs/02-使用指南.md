## 首次使用 - 标定流程

### 1. 准备标定板

**标定板要求：**
- **棋盘格**：推荐9×6或11×8
- **圆点板**：推荐7×5或9×6
- **方格大小**：10mm（根据实际调整）
- **要求**：标定板平整、清洁

### 2. 启动标定

```bash
curl -X POST "http://localhost:8000/api/v1/calibration/start" \
  -H "Content-Type: application/json" \
  -d '{
    "method": "chessboard",
    "board_size": [9, 6],
    "square_size_mm": 10.0
  }'
```

**响应示例：**
```json
{
  "message": "标定已启动",
  "calibration_id": "cal_12345"
}
```

### 3. 采集标定图像

**要求：**
- 采集至少10张不同角度的图像（推荐15-20张）
- 确保标定板覆盖整个视野
- 确保图像清晰，光照均匀
- 不同位置和角度

**上传图像：**
```bash
curl -X POST "http://localhost:8000/api/v1/calibration/upload-image" \
  -F "file=@calibration_image_1.jpg" \
  -F "calibration_id=cal_12345"
```

### 4. 计算标定参数

```bash
curl -X POST "http://localhost:8000/api/v1/calibration/calculate" \
  -H "Content-Type: application/json" \
  -d '{"calibration_id": "cal_12345"}'
```

**响应示例：**
```json
{
  "calibration_id": "cal_12345",
  "status": "success",
  "parameters": {
    "pixel_size_x_mm": 0.005,
    "pixel_size_y_mm": 0.005,
    "accuracy_mm": 0.03,
    "reprojection_error": 0.08
  }
}
```

### 5. 验证标定精度

**检查指标：**
- 重投影误差 < 0.1像素
- 像素到物理坐标转换精度达到0.05mm

**获取标定参数：**
```bash
curl http://localhost:8000/api/v1/calibration/parameters
```

## 日常检测流程

### 1. 配置检测参数

**通过API配置：**
```bash
# 配置回吸高度阈值
curl -X POST "http://localhost:8000/api/v1/config/update" \
  -H "Content-Type: application/json" \
  -d '{
    "algorithm": "suction_height",
    "parameters": {
      "min_mm": 3.0,
      "max_mm": 5.0
    }
  }'
```

**配置项说明：**
- `offset_threshold_mm`: 偏移距离阈值（默认0.1mm）
- `angle_threshold_deg`: 角度偏移阈值（默认2.0°）
- `contamination_threshold`: 脏污阈值（默认0.3）
- `suction_height_min_mm`: 回吸高度最小值（默认3.0mm）
- `suction_height_max_mm`: 回吸高度最大值（默认5.0mm）
- `liquid_width_threshold_mm`: 喷液宽度阈值（默认2.0mm）
- `bubble_count_threshold`: 气泡数量阈值（默认5）

### 2. 连接设备

**连接相机和PLC：**
- 系统启动时自动连接
- 检查日志确认连接状态
- 查看健康检查接口

### 3. 启动检测

```bash
curl -X POST "http://localhost:8000/api/v1/detection/start" \
  -H "Content-Type: application/json" \
  -d '{
    "camera_id": "default",
    "algorithms": [
      "nozzle_offset",
      "suction_height",
      "liquid_width",
      "contamination"
    ]
  }'
```

### 4. PLC信号触发

**工作流程：**
1. PLC发送开始信号 → 系统自动开始录制和检测
2. 实时处理视频帧，执行检测算法
3. 检测结果通过MQTT发布
4. 异常情况自动报警
5. PLC发送停止信号 → 系统自动停止录制
6. 视频自动上传到MinIO

### 5. 查看检测结果

**获取检测结果：**
```bash
curl "http://localhost:8000/api/v1/detection/results?camera_id=default&limit=100"
```

**响应示例：**
```json
{
  "results": [
    {
      "algorithm_name": "nozzle_offset",
      "timestamp": "2024-01-01 12:00:00",
      "frame_id": 12345,
      "result": {
        "offset_x_mm": 0.12,
        "offset_y_mm": 0.08,
        "offset_distance_mm": 0.15
      },
      "status": "normal"
    }
  ],
  "total": 100
}
```

**MQTT订阅结果：**
```bash
# 订阅检测结果主题
mosquitto_sub -h localhost -t "nozzle/inspection/result" -v

# 订阅报警主题
mosquitto_sub -h localhost -t "nozzle/inspection/alarm" -v
```

## 参数配置

### 获取当前配置

```bash
curl http://localhost:8000/api/v1/config/algorithms
```

### 更新配置

```bash
curl -X POST "http://localhost:8000/api/v1/config/update" \
  -H "Content-Type: application/json" \
  -d '{
    "algorithm": "算法名称",
    "parameters": {
      "参数名": "参数值"
    }
  }'
```

### 配置项说明

| 算法 | 参数 | 说明 | 默认值 |
|------|------|------|--------|
| nozzle_offset | threshold_mm | 偏移距离阈值 | 0.1mm |
| angle_offset | threshold_deg | 角度偏移阈值 | 2.0° |
| contamination | threshold | 脏污阈值 | 0.3 |
| suction_height | min_mm | 回吸高度最小值 | 3.0mm |
| suction_height | max_mm | 回吸高度最大值 | 5.0mm |
| liquid_width | threshold_mm | 喷液宽度阈值 | 2.0mm |
| bubble | count_threshold | 气泡数量阈值 | 5 |

## 视频管理

### 列出视频

```bash
curl "http://localhost:8000/api/v1/videos?limit=100&offset=0"
```

### 获取视频URL

```bash
curl "http://localhost:8000/api/v1/videos/{video_id}/url?expires=3600"
```

### 视频回放

1. 获取视频列表
2. 选择要回放的视频
3. 获取视频URL
4. 在浏览器或播放器中打开URL
