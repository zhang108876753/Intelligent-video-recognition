## 相机连接问题

### 问题：无法连接海康相机

**排查步骤：**

1. **检查网络连接**
   ```bash
   ping 192.168.1.64
   ```

2. **检查RTSP地址格式**
   ```
   rtsp://用户名:密码@IP:554/Streaming/Channels/101
   ```

3. **使用ffmpeg测试连接**
   ```bash
   ffmpeg -rtsp_transport tcp -i "rtsp://admin:password@192.168.1.64:554/Streaming/Channels/101" -frames:v 1 test.jpg
   ```

4. **检查防火墙**
   ```bash
   # Linux
   sudo ufw allow 554/tcp
   ```

5. **查看后端日志**
   ```bash
   tail -f backend/logs/app.log | grep camera
   ```

**解决方案：**
- 确认相机用户名和密码
- 检查相机是否支持RTSP
- 确认网络连接正常
- 检查相机固件版本

## PLC通信问题

### 问题：无法读取PLC信号

**排查步骤：**

1. **检查PLC IP和端口**
   ```bash
   telnet 192.168.1.100 502
   ```

2. **检查Modbus配置**
   - 从站ID是否正确
   - 地址是否正确
   - 数据类型是否正确（线圈/保持寄存器）

3. **使用Modbus调试工具测试**
   - Modbus Poll（Windows）
   - QModMaster（Linux）

4. **查看PLC日志**
   ```bash
   tail -f backend/logs/app.log | grep plc
   ```

**解决方案：**
- 确认PLC Modbus配置
- 检查网络连接
- 确认从站ID和地址
- 检查PLC程序中的信号地址

## 标定精度问题

### 问题：标定精度不达标（重投影误差>0.1像素）

**排查步骤：**

1. **检查标定图像质量**
   - 图像是否清晰
   - 标定板是否平整
   - 光照是否均匀

2. **检查标定图像数量**
   - 至少需要10张
   - 推荐15-20张

3. **检查标定板覆盖范围**
   - 标定板应覆盖整个视野
   - 不同角度和位置

4. **检查标定参数**
   - 棋盘格大小是否正确
   - 方格大小是否正确

**解决方案：**
- 增加标定图像数量
- 确保标定板平整
- 改善光照条件
- 检查相机焦距设置

## 检测精度问题

### 问题：检测精度无法达到0.05mm

**排查步骤：**

1. **检查标定参数**
   ```bash
   curl http://localhost:8000/api/v1/calibration/parameters
   ```

2. **检查相机分辨率**
   - 建议≥4MP（2048×2048）
   - 检查实际分辨率设置

3. **检查算法参数**
   - 亚像素处理是否启用
   - 边缘检测参数是否合适

4. **检查视野大小**
   - 视野越小，精度越高
   - 建议视野≤10mm×10mm

**解决方案：**
- 重新标定，确保精度
- 使用更高分辨率相机
- 缩小视野范围
- 优化算法参数

## 实时性问题

### 问题：无法达到60fps处理速度

**排查步骤：**

1. **检查CPU使用率**
   ```bash
   top
   ```

2. **检查算法处理时间**
   ```python
   import time
   start = time.time()
   result = algorithm.detect(frame)
   print(f"处理时间: {(time.time() - start) * 1000:.2f}ms")
   ```

3. **检查帧率设置**
   - 检查相机实际帧率
   - 检查处理线程是否阻塞

**解决方案：**
- 使用GPU加速（CUDA）
- 优化算法，减少计算量
- 使用帧采样（非关键帧降低频率）
- 优化ROI区域
- 升级硬件配置

## 存储问题

### 问题：视频上传MinIO失败

**排查步骤：**

1. **检查MinIO连接**
   ```bash
   curl http://localhost:9000/minio/health/live
   ```

2. **检查存储桶是否存在**
   ```bash
   mc ls minio/nozzle-videos
   ```

3. **检查磁盘空间**
   ```bash
   df -h
   ```

4. **查看MinIO日志**
   ```bash
   docker-compose logs minio
   ```

**解决方案：**
- 检查MinIO配置
- 确保存储桶存在
- 清理磁盘空间
- 检查网络连接

## 其他问题

### 问题：服务启动失败

**排查步骤：**

1. **检查依赖安装**
   ```bash
   pip list | grep opencv
   pip list | grep fastapi
   ```

2. **检查端口占用**
   ```bash
   # Linux
   netstat -tulpn | grep 8000
   # Windows
   netstat -ano | findstr 8000
   ```

3. **检查环境变量**
   ```bash
   cat .env
   ```

4. **查看错误日志**
   ```bash
   tail -f backend/logs/app.log
   ```

### 问题：API请求失败

**排查步骤：**

1. **检查服务是否运行**
   ```bash
   curl http://localhost:8000/health
   ```

2. **检查请求格式**
   - 查看API文档
   - 检查请求体格式

3. **查看API日志**
   ```bash
   tail -f backend/logs/app.log | grep api
   ```
