## 环境要求

### 硬件要求
- **CPU**: ≥4核（推荐8核）
- **内存**: ≥8GB（推荐16GB）
- **GPU**: 可选，用于算法加速（NVIDIA GPU with CUDA）
- **存储**: ≥100GB可用空间

### 软件要求
- **操作系统**: Linux (Ubuntu 20.04+) 或 Windows 10+
- **Python**: 3.9 或更高版本
- **Docker**: 20.10+ 和 Docker Compose 1.29+
- **Node.js**: 16+（前端开发需要）

### 硬件设备
- **工业相机**: 海康威视工业相机（支持RTSP）
- **PLC设备**: 支持Modbus TCP协议
- **网络**: 相机、PLC、服务器在同一网络

## 安装步骤

### 1. 克隆项目

```bash
git clone <repository-url>
cd semiconductor-nozzle-inspection-system
```

### 2. 创建Python虚拟环境

```bash
# Linux/Mac
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

### 3. 安装Python依赖

```bash
pip install -r requirements.txt
```

### 4. 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑.env文件，配置以下参数
```

**必需配置项：**
```env
# 相机配置
CAMERA_IP=192.168.1.64
CAMERA_USERNAME=admin
CAMERA_PASSWORD=admin123

# PLC配置
PLC_HOST=192.168.1.100
PLC_PORT=502

# MinIO配置
MINIO_ENDPOINT=localhost:9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin

# MQTT配置
MQTT_BROKER=localhost
MQTT_PORT=1883
```

## 配置说明

### 相机配置

**海康相机RTSP地址格式：**
```
rtsp://用户名:密码@IP地址:554/Streaming/Channels/101
```

**测试相机连接：**
```bash
ffmpeg -rtsp_transport tcp -i "rtsp://admin:password@192.168.1.64:554/Streaming/Channels/101" -frames:v 1 test.jpg
```

### PLC配置

**Modbus TCP配置：**
- 从站ID（Slave ID）：通常为1
- 开始信号地址：线圈地址（如0）
- 停止信号地址：线圈地址（如1）

**测试PLC连接：**
```python
from pymodbus.client import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)
if client.connect():
    result = client.read_coils(0, 1, slave=1)
    print(f"信号状态: {result.bits[0]}")
    client.close()
```

## 启动服务

### 1. 启动基础设施服务

```bash
# 启动PostgreSQL、Redis、MinIO、MQTT
docker-compose up -d

# 检查服务状态
docker-compose ps

# 查看服务日志
docker-compose logs -f
```

**验证服务：**
- PostgreSQL: `psql -h localhost -U user -d nozzle_db`
- Redis: `redis-cli ping`（应返回PONG）
- MinIO: 访问 `http://localhost:9001`（用户名/密码：minioadmin/minioadmin）
- MQTT: 使用MQTT客户端连接 `localhost:1883`

### 2. 启动后端服务

```bash
cd backend
python main.py
```

后端服务将在 `http://localhost:8000` 启动

### 3. 启动前端服务（待开发）

```bash
cd frontend
npm install
npm run dev
```

前端服务将在 `http://localhost:3000` 启动
