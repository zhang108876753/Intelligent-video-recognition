**数据库表设计：**
```sql
-- 视频记录表
CREATE TABLE videos (
    id SERIAL PRIMARY KEY,
    filename VARCHAR(255) NOT NULL,
    object_name VARCHAR(255) NOT NULL,
    camera_id VARCHAR(50),
    start_time TIMESTAMP,
    end_time TIMESTAMP,
    duration_seconds INTEGER,
    file_size BIGINT,
    status VARCHAR(20),  -- recording/completed/failed
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 检测结果表
CREATE TABLE detection_results (
    id SERIAL PRIMARY KEY,
    video_id INTEGER REFERENCES videos(id),
    frame_id INTEGER,
    algorithm_name VARCHAR(50),
    result JSONB,
    status VARCHAR(20),  -- normal/warning/error
    timestamp TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 标定记录表
CREATE TABLE calibrations (
    id SERIAL PRIMARY KEY,
    calibration_id VARCHAR(50) UNIQUE,
    method VARCHAR(20),
    parameters JSONB,
    accuracy_mm FLOAT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**测试要求：**
- 能够成功上传视频到MinIO
- 能够正确存储和查询元数据
- 能够生成预签名URL

## 风险控制

1. **算法精度不达标**
   - 风险：精度可能无法达到0.05mm
   - 应对：提前验证，准备备选方案（降低精度要求或增加硬件）

2. **实时性不达标**
   - 风险：60fps处理压力大
   - 应对：使用GPU加速，优化算法，降低处理频率

3. **集成复杂度高**
   - 风险：多系统集成可能出现问题
   - 应对：分模块开发，充分测试，预留调试时间

4. **数据不足**
   - 风险：算法训练和调优需要大量数据
   - 应对：提前收集数据，使用数据增强，准备模拟数据
